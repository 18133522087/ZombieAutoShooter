## 2. 关键设置

### 2.1 Domain Reload（必须遵守）

`Enter Play Mode Options` 已启用且 **Disable Domain Reload**（保持快速进入 Play）。因此**所有静态状态在退出 Play 后不会自动清空**，必须显式重置：

```csharp
[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.SubsystemRegistration)]
static void ResetStatics()
{
    // 对象池字典、单例实例、静态计数器、静态事件订阅、缓存引用 全部在这里清空
}
```

要求：
- 任何 `static` 可变字段（池、单例、计数、缓存）都必须有重置入口。
- QA 必须连续 Play 两次，确认第二次行为与第一次一致（无残留僵尸/经验/弹窗/计时）。

### 2.2 分辨率 / 窗口

- PlayerSettings：1920×1080、Windowed、可缩放（已改并保存）。
- 截图验收统一 1920×1080（Game 视图）。

### 2.3 音频

- `Assets/Editor/PlaceholderAudioGenerator.cs`：菜单 `Tools/ZombieAutoShooter/Generate Placeholder Audio` 程序化生成 15 个 WAV 到 `Assets/Audio/`（无外部素材、无第三方包）。
- 导入设置：SFX = DecompressOnLoad + PCM；BGM = CompressedInMemory + preload。
- 替换音频：改 `AudioConfig` SO 的 clip 引用即可，不改代码。
- 若想要 AI 音频：在 Unity MCP 面板配置 fal key，用 `generate_audio` 生成后替换同 id 的 wav。
- `AudioMixer` / `AudioConfig` / `AudioManager` 在 V1 开始时创建。

## 3. MCP 使用纪律

1. 调工具前先确认 `mcpforunity://editor/state` 的 `advice.ready_for_tools == true`。
2. **Play/Stop、工具组切换、脚本重编译之后**，MCP 工具注册会短暂失效（返回 `unknown tool`）→ 等 2–3 秒重试一次；连续两次失败再上报。
3. `execute_code` 的编译器是 **CodeDom（C# 6）**：不能使用元组、`out var`、模式匹配、`?.` 之外的 C# 7+ 语法；正式脚本不受影响。
4. **同一时刻只有一个 agent 做 Unity 写操作**（场景/Prefab/资产/进 Play/截图）；并行只允许在互斥文件范围（脚本、Config）。
5. 不手写 `.unity` / `.prefab` / `.asset` / `.meta` 的 YAML 绕过 MCP。
6. 每次 Play Mode 自检后读 `read_console`，必须 0 error；有 error 先修再继续。
