## 4. 已知限制

- **静态模型**：僵尸和 Boss 还没有行走/攻击/受击动画；主角有程序化动画预览。
- 敌人 Prefab **只有外观**（没有 Rigidbody/Collider/脚本）；V1 阶段会加碰撞体和逻辑组件。
- 远程僵尸的兜帽目前是球体，可读性一般，后续可加兜帽开口、破洞、面罩。
- Boss 偏"方块机器人感"，如果要更生物感可以加肌肉块/肋骨弧度/皮肤褶皱。
- 武器是低模占位，还没有枪口火焰/抛壳/换弹动作（提示词也不做换弹）。
